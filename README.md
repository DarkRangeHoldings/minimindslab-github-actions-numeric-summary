# Numeric Summary

Summarize finite numeric values from JSON input with deterministic count, min, max, sum, mean, and median outputs.

Generated by MiniMindsLab 02.13 GitHub Action Factory.

## Usage

```yaml
- uses: ./path-to-action
  id: miniminds
  with:
    payload: '{"values":[1,2,3,4]}'
- run: echo '${{ steps.miniminds.outputs.result }}'
```

Runtime: Node 24. No external dependencies. No network access.
